## Read-only backend review

`QueryService::referenced_sql_sources` validates DTO, opens restricted memory DuckDB, disables external access/locks configuration, extracts exactly one statement, validates conservative tokens and calls native `duckdb_get_table_names`. Returned names must match registered aliases. It does not prepare/execute user SQL in the parent. Root commands call it **before** `source_specs`, then engine independently filters request bindings before schema/profile/fingerprint/CSV artifacts. Unused inputs therefore do not enter task cancellation membership or artifact guards. No new arbitrary file/network execution path found in this analysis helper.

Worker lifetime order reviewed: CSV artifact guards are acquired before WorkerProcess. On early return, process Drop kills/waits before earlier guards drop. Successful path detects finished child and validates exit before result publication/explicit guard release. Cancellation reason is stored before flag publication; final task status preserves it rather than replacing it with generic cancellation. Completed tasks are skipped by source cancellation; retained result owns only its independent result lease. Source inspection cannot replace actual process/CSV lease timing proof.
