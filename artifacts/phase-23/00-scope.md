# Phase 23 · SQL Results 작업 보기

목표는 Phase 22 SQL 결과에 파일 뷰어의 정렬, 타입별 필터, Find를 연결하고 현재 보기의 내보내기를 추가하는 것이다. Query와 출력 영역의 높이는 경계 드래그와 키보드로 조정한다.

SQL 실행 시 만든 결과 스냅샷이 기준이다. 새 보기 요청은 기준 결과와 보기 ID, 기존 QueryPlan을 전달한다. 조회, 찾기, 복사, 파일 내보내기는 확정된 보기 ID에 묶인다. 변경을 적용하는 동안 마지막 성공 보기를 유지하고, 실패와 취소도 기존 보기를 유지한다. 새 SQL 결과가 확정되거나 Clear를 누르면 관련 보기와 자원을 해제한다.

전체 결과 내보내기는 원래 스냅샷을 사용한다. 현재 보기 내보내기는 적용된 필터와 정렬 순서를 반영한다. Find는 탐색 좌표를 계산하며 행 집합은 유지한다.

범위는 결과 파생 보기와 레이아웃이다. 쿼리 기록, 파일 수정, 새 런타임, capability 추가는 후속 범위다. 버전은 Phase 23과 맞춘 0.23.0이다.
