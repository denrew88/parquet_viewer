# Phase 24 SQL 멀티탭과 차트 작업 공간

## 목표

파일과 SQL 작업 공간 옆에 독립 Charts 작업 공간을 둔다. 여러 SQL 탭과 Sheet를
한 실행 세션에서 유지한다. Sheet 안의 차트는 개별 소스와 설정을 가지며 카드 배치를
키보드 또는 포인터로 변경할 수 있다. 종료 후 세션 복원과 SQL 결과 영구 보관은 후속 범위다.

## 수명 및 데이터 계약

- SQL 탭 ID는 편집기와 마지막 성공 SELECT를 식별한다. 실행 ID와 결과 ID는 개별 결과를 식별한다.
  성공 결과가 게시될 때만 연결된 차트가 갱신된다. 실패, 취소, EXPLAIN은 마지막 결과를 유지한다.
  새 결과의 축 열 이름과 타입이 달라지거나 이름이 중복되면 안전하게 재선택을 요구한다.
- SQL 화면과 고정된 차트가 결과를 공유한다. 탭을 닫거나 교체하면 해당 소유권을 해제한다.
  연결된 차트와 작업의 수명 및 임시 저장소의 행·용량·동시 실행 상한을 적용한다.
- 파일 전체 차트는 문서 ID와 세션 ID를 사용한다. 세션 닫기나 교체 때 재연결 상태가 된다.
- 파일 및 SQL 그리드의 선택 블록은 현재 커밋된 필터·정렬 보기를 통해 선택한 행·열을
  검증하고, 상한이 있는 타입 보존 스냅샷을 Rust에 캡처한다. 그리드 페이지와 클립보드에
  의존하지 않는다. 차트가 사라지면 캡처를 해제한다.
- 파일 전체 및 SQL 결과는 투영된 배치로 읽고 차트 계산은 백그라운드에서 수행한다.
  작업 ID와 최신 차트 설정을 확인해 지연된 결과를 폐기한다. UI는 취소와 실패를 표시한다.
- 차트 종류는 scatter, violin, histogram, box, line, bar이다. 유효·제외 행 수, 표본 또는
  추정 여부를 표시한다. 큰 입력은 결정적 표본, 제한된 버킷·그룹·점 수를 사용한다.
  날짜 및 고정소수점은 원래 타입에서 읽고 축 기준점을 차감한 뒤 표시 좌표를 만든다.

## 소유권

- 루트: 공통 IPC 계약, React 앱·SQL 멀티탭·그리드 진입점 통합, Rust 파일/SQL 소스 및
  결과 수명 연결, 빌드·공통 문서·정식 산출물.
- Rust 담당: Rust 차트 DTO·집계·표본·작업/블록 저장소·단위 테스트.
- Grid UX 담당: Charts Sheet, 카드, 설정, 상태, ECharts 렌더링 및 컴포넌트 테스트.
- Quality 담당: 독립 테스트 설계, fixture, 브라우저·실제 Tauri 인수 및 성능 검증.

## 대표 인수 흐름

파일 산점도, SQL A 바이올린, SQL A 필터 보기에서 선택한 박스 플롯, SQL B 시계열을
같은 Sheet에 둔다. A를 다시 실행하면 바이올린만 새 결과를 표시한다. B를 취소하거나
실패시키면 시계열은 이전 결과를 유지한다. 최소·중간·넓은 창에서 상태와 레이아웃을
검증하고 최종 EXE의 크기, 버전, 해시를 남긴다.
