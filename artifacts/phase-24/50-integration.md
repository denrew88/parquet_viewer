# Phase 24 통합 및 검증

## 제품 동작

- SQL 탭별 편집기와 마지막 성공 결과를 유지한다. 대기열에서 실행을 직렬화하고 대기·실행을
  각각 취소할 수 있다. 성공한 새 결과만 연결된 차트에 반영한다.
- 독립 Charts 작업 공간에서 Sheet와 카드를 추가·복제·편집한다. 포인터와 키보드로 카드를
  이동하거나 크기를 조절한다. 카드별 파일 연결, SQL 최신 결과 추적, 실행 결과 고정과
  선택 블록을 지원한다.
- 파일 Data와 SQL Results의 선택 블록은 커밋된 보기의 논리 행 순서와 선택 열을 보존한다.
  Rust는 필요한 열을 배치로 읽고, ECharts Canvas에는 제한된 시각화 데이터만 전달한다.
  산점도·바이올린·히스토그램·박스·선·가로 막대 여섯 종류를 지원한다.

## 검증

- 프런트엔드 포맷·린트·타입 검사를 통과했다. 전체 단위 테스트의 876건 중 첫 통합 검증에서
  868건이 통과했다. 실패가 나온 App과 그리드 파일을 단독 재실행해 각각 65건, 69건 모두
  통과했다. SQL 편집기 테스트도 단독으로 19건 모두 통과했다.
- Phase 24 브라우저 인수 테스트는 3개 viewport에서 6건 통과했다. 전체 회귀 243건 중
  241건이 첫 실행에서 통과했다. 실패한 기존 SQL 식별자 삽입 시나리오는 동일 세 viewport에서
  다시 실행해 3건 모두 통과했다. 보관된 과거 UI 증거 313개의 SHA-256을 검증했다.
- Rust 포맷과 Release Clippy를 통과했다. 초기 차트 단위 테스트 실행은 Windows 앱 제어
  오류 4551로 차단됐다. 최종 일반 빌드 환경에서 Release Rust 테스트 424건이 통과했다.
  기존 별도 실행 대상 18건은 ignored 상태다. Phase 24의 차트 및 SQL 결과 고정 테스트는 모두 통과했다.
- 실제 Windows WebView2에서 네 차트의 캔버스, SQL A의 갱신과 SQL B의 실패 격리, 원본
  열 재선택, 필터·역정렬한 211행 선택 블록, 고정 결과의 해제, 대용량 처리와 취소를 확인했다.

## 초기 제품 후보

v0.24.0 제품 후보 EXE는 61,490,176바이트이며, v0.23.0 정식 EXE보다 512,000바이트
크다. x64 NSIS 설치 파일은 14,363,078바이트다. Windows 파일 버전과 제품 버전은
모두 0.24.0이다.

최신 차트 설정을 포함한 제품 EXE는 후보 경로에서 Windows 검증 13건을 통과했다. 로그 척도,
히스토그램 경계와 바이올린 대역폭을 실제 IPC로 검증했고, WebView2에서 척도와 구간 수를
변경해 차트가 갱신되는 것을 확인했다. 정식 경로에서는 SHA-256이 같은 EXE의 시작이
Windows 앱 제어 정책에 차단되어, 기존 v0.23.0을 복구하고 해시를 확인했다.

211행 키보드 선택을 검증할 때 CDP가 화면 프레임보다 빠르게 키를 연속 주입하면 React 오류
185가 재현됐다. 입력 사이에 화면 프레임을 기다리도록 검증 스크립트를 조정했다. 같은
EXE에서 선택 행과 집계 결과를 검증했고, 콘솔 오류 검사도 통과했다.
최신 Release Rust 테스트 실행 파일은 컴파일됐으나 Windows 앱 제어 오류 4551로 시작이
차단됐다.
