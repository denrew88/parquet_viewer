# Phase 24 브라우저 상호작용

- 실행: `node scripts/dev-check.mjs phase24-e2e`. 세 viewport에서 각 2개, 총 6개 통과.
- T-P24-001/002/006은 SQL 탭별 편집기와 이전 성공 결과 보존을 확인한다. A 재실행 시 A 차트의 결과 ID만 변경되고 B의 결과를 고정한 차트는 B 재실행·닫기 뒤에도 유지된다. A 오류·취소·EXPLAIN은 A 차트의 마지막 결과를 보존한다. A가 실행 중인 동안 B 요청을 대기시키고 A 취소 뒤 B가 실행된다. 카드별 필터는 A의 4행 중 1행만 남긴다. 키보드 이동·높이·너비와 넓은 화면의 포인터 드래그 이동 및 높이 조절을 확인했다.
- T-P24-003/004는 파일 그리드 우클릭과 SQL 그리드 Shift+F10으로 각각 논리적 2×2 범위를 별도 Sheet에 보내는 동작을 확인한다. SQL 재실행과 Sheet 전환 뒤 각 범위 카드가 남고, 다른 Sheet를 닫아도 남은 범위 카드를 사용할 수 있다.
- 최소 창에서 결과 그리드의 행이 높이보다 작게 배치될 때 활성 셀을 다시 맞추는 스크롤이 반복되어 컨텍스트 메뉴가 닫히는 결함을 재현했다. 표시 가능한 높이에 한 행을 담을 수 없으면 위쪽만 맞추도록 수정한 뒤 최소 창 단독과 전체 6건을 다시 통과했다.
- 화면과 geometry 판정은 `visual-review.md` 및 `geometry-results.json`에 기록했다. 데이터 계산 정밀도와 실제 WebView2 검증은 별도 판정이다.
