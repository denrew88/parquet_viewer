# Phase 24 Windows WebView2 검증

별도 Windows 제품 식별자를 사용하는 Release 검증 후보로 1180×760, DPR 1에서 실행했다.
앱의 내부 버전은 0.24.0이다. 이 검증 후보의 Windows 리소스 버전은 0.23.0이었으며
제품 후보의 빌드 설정에서 버전을 명시하도록 수정했다.

같은 Sheet에 파일 산점도, SQL A 바이올린과 211행 선택 박스, SQL B 시계열을 표시했다.
SQL A의 다음 성공 결과는 바이올린만 바꿨고, SQL B 실패 시 이전 시계열을 유지했다.
선택 블록의 첫·마지막 원본 행 번호는 319와 109이며 그룹 수와 중앙값은 독립 fixture와
일치했다. 파일에서 캡처한 동일 필터·정렬 블록도 확인했다. 결과 고정 후 SQL 탭 소유권
해제, 최종 해제, 100,001셀 거부, 대용량 정수·decimal·나노초 좌표, NaN·Inf 제외,
히스토그램과 막대 합계를 실제 IPC로 확인했다.

| Parquet 입력 | IPC 계산 | 설정부터 캔버스까지 | 점 수 | JSON 응답 |
| --- | ---: | ---: | ---: | ---: |
| 10,000행 | 525 ms | 478 ms | 10,000 | 111,623 B |
| 100,000행 | 1,056 ms | 528 ms | 20,000 | 223,082 B |
| 1,000,000행 | 3,479 ms | 5,621 ms | 20,000 | 223,073 B |

각 열의 시간은 별도 실행에서 측정했다. 100만 행 요청의 취소 응답은 61 ms였다.
커머스 JOIN 결과 249,045행의 바이올린은 6,157 ms에 2,688 B를 반환했다.
최초 커머스 측정은 CSV 준비가 끝나기 전에 실행해 실패했으며, 준비 완료를 기다리는
독립 재실행에서 통과했다. WebView2 콘솔 오류는 없었다.
