# Phase 24 차트 화면 시각 검토

Chromium의 1440×900, 1024×768, 800×600 캡처를 각각 이미지로 열었다.
세 화면 모두 같은 Sheet에서 SQL을 따르는 분포와 실행 결과에 고정한 분포를
표시하며 오른쪽에 고정한 카드의 설정을 연 상태다.

| 크기 | 관찰 | 판정 |
| --- | --- | --- |
| 1440×900 | 568px 카드 두 개와 255px 설정 패널이 분리된다. 선택 테두리, 출처 이름, 필터 적용 후 유효 행 수가 읽힌다. | PASS |
| 1024×768 | 약 370px 카드 두 개를 유지한다. 범위가 좁아지면서 차트 눈금 수가 줄어든다. 설정 하단은 패널 자체의 세로 스크롤 범위다. | PASS |
| 800×600 | 555px 카드 한 열로 전환하고 206px 설정 패널을 유지한다. 두 번째 카드는 시트의 세로 스크롤로 이어진다. 네이티브 select의 긴 고정 결과 표시가 축약되지만 카드 제목 아래에서 SQL 탭 이름을 확인할 수 있다. | PASS |

작업 공간과 설정 패널에 의도하지 않은 가로 스크롤이 없다. 카드·축·툴바가
겹치지 않는다. 위치·크기 수치는 geometry-results.json에 있으며, 입력 성공 여부는
Playwright 테스트 결과에 구분하여 기록한다.
